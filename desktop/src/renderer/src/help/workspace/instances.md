# Tabs and windows

Each running instance has its own application page. Switching pages preserves the instance's data and running state.

## Switch instances

The instance list groups open applications by category. Select a category header to expand or collapse its instances. Collapsing a category keeps its instances running. Each category remembers its state when navigating between workspace pages.

Select a tab in Home or select an instance in the instance list. Selecting an external instance brings its independent window forward.

Use the tab strip's arrow keys to move between tabs when a tab has keyboard focus.

## Move a tab to a window

Select the external-window icon at the right of the tab strip, or choose **View > Move Active Instance to Window**.

The same application page moves to an independent window. This does not create a new instance or reset the current session.

## Dock a window

Select **Dock to Home** in the independent window's title bar. You can also select the dock icon beside an external instance in Home's instance list.

The window closes after its page returns to Home. The application stays running.

## Close an instance

Use the tab's close button, the close button in the instance list, or **File > Close Active Instance**. Closing an independent window also closes that instance.

## Close the workspace

The **Close apps with the workspace** preference controls whether instances also close. If it is disabled, docked pages move to independent windows when the workspace closes.

Use the Home icon in an independent window's title bar to reopen the workspace. See [Preferences](settings.md).
