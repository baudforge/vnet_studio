# Application management

Apps lists the applications available in the current workspace.

## Find an application

Use the search field to filter by application name, description, or tags. Press `/` while Apps is selected to focus the search field.

## Enable or disable launches

The **Enabled** switch controls whether new instances can be launched. Disabling an application leaves its existing instances running.

Application preferences are saved and restored the next time the workspace opens.

## Launch instances

Select **Launch app** to start the first instance. Select **Launch another** to create another instance of the same application.

Each launch receives its own instance number and opens a tab in Home. See [Tabs and windows](instances.md) for navigation and docking controls.

Every available application has its own root in the Docs document tree, including disabled applications.
