# Preferences

Select the Settings icon at the bottom of the sidebar, or choose **File > Settings**.

## Appearance

Choose **Light**, **Dark**, or **System**. System follows the operating system's appearance.

The theme applies to the workspace and every open application instance.

## Application instances

**Close apps with the workspace** is enabled by default.

- Enabled: closing the workspace closes all application instances.
- Disabled: instances remain running in independent windows. Docked pages move to windows automatically.

Preferences are saved automatically on this computer. See [Tabs and windows](instances.md#close-the-workspace) for reopening the workspace.
