# Keyboard shortcuts

Use Ctrl on Windows and Linux, or Command on macOS, for the workspace shortcuts below.

| Action              | Windows / Linux | macOS       |
| ------------------- | --------------- | ----------- |
| Show Home           | Ctrl + 1        | Command + 1 |
| Show Logs           | Ctrl + 2        | Command + 2 |
| Show Apps           | Ctrl + 3        | Command + 3 |
| Show Docs           | Ctrl + 4        | Command + 4 |
| Open Settings       | Ctrl + ,        | Command + , |
| Search applications | / in Apps       | / in Apps   |

## Menus

Use **Alt + F**, **Alt + E**, **Alt + V**, or **Alt + H** to open File, Edit, View, or Help while working in the workspace or a docked application.

Arrow keys move between menu buttons when a button has keyboard focus. Enter or Space opens its menu.

## Tabs

When a Home tab has focus, use Left or Right to select an adjacent tab. Home and End select the first or last tab.

## Editing

The Edit menu provides Undo, Redo, Cut, Copy, Paste, and Select All for the active view. Documentation is read-only; its text can be selected and copied.
