# Getting started

VNet Studio opens applications in a shared desktop workspace. Each application launch creates an independent instance.

## Open an application

1. Select **Apps** in the icon sidebar.
2. Find an application and leave its **Enabled** switch on.
3. Select **Launch app**. The instance opens as a new tab in **Home**.
4. Select **Launch another** in Apps to create another independent instance.

For the first application, see the [Bus Trace Demo manual](../applications/bus-trace-demo/overview.md).

## Workspace navigation

| Area     | Purpose                                                          |
| -------- | ---------------------------------------------------------------- |
| Home     | Work with running instances in tabs and manage external windows. |
| Logs     | View runtime messages, warnings, and errors.                     |
| Apps     | Find applications, enable launches, and start new instances.     |
| Docs     | Read the main program manual and application manuals.            |
| Settings | Choose the theme and workspace exit behavior.                    |

Click the Home icon again while Home is selected to hide or show its instance list. The open application remains running.
