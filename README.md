# vnet_studio

A toolkit for automotive bus development and testing, providing SDKs, command line tools, and application examples.

The project uses C++ for its core and Electron for its UI.

## Top-Level Directories

```text
vnet_studio/
├── sdk/        # SDK libraries
├── tools/      # Command line tools
├── desktop/    # Electron UI
├── proto/      # Protocol definitions
├── examples/   # Examples
├── tests/      # Tests
├── docs/       # Documentation
└── scripts/    # Build scripts
```
